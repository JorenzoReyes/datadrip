## 🎨 Visual Layout Features

When you have 10+ insights:

1. **Scrollable Panel**: The insights panel becomes scrollable (max-height: 600px) so you can browse through all insights
2. **Smart Counter**: Shows "Showing X actionable insights based on your data"
3. **Forecast Badge**: Special indicator when forecasting insights are included
4. **Priority Grouping**: High priority insights appear first (sorted by urgency)
5. **Type Icons**: 
   - 🔮 Forecast
   - 📦 Inventory
   - 🎯 Promotion
   - 📈 Trend
   - 💬 Feedback
6. **Dismiss Option**: Click X on any insight to remove it from view

## 📈 What Determines Insight Count?

The system generates **8-10+ insights** based on:

### **Your Data Richness**
- **More products** → More product-specific insights
- **Multiple shops** → Shop-specific performance insights
- **Rich sales history** → Better trend and pattern analysis
- **Multiple categories** → Category-level insights

### **Types of Insights Generated**

1. **Forecast Insights (2-3)**
   - Sales predictions (weekly/monthly)
   - Inventory depletion forecasts
   - Growth trend forecasts

2. **Inventory Insights (2-4)**
   - Low stock alerts (one per critical product)
   - Overstock warnings
   - Restock recommendations

3. **Promotion Insights (2-3)**
   - Top product opportunities
   - Category growth opportunities
   - Bundle recommendations

4. **Trend Insights (1-2)**
   - Sales pattern analysis
   - Best selling days/times
   - Seasonal trends

5. **Feedback Insights (1-2)**
   - Shop rating analysis
   - Customer satisfaction trends
   - Platform performance comparison

## 🚀 How to Get More Insights

To see more insights like the example above:

1. **Add More Products** - More SKUs = more product-specific insights
2. **Record Sales Data** - Rich sales history enables better forecasting
3. **Connect Multiple Shops** - Get insights per shop/platform
4. **Add Product Categories** - Enable category-level analysis
5. **Accumulate Transaction History** - 30+ days of data improves accuracy

## 💡 Dynamic Scaling

The system is **intelligent**:
- With limited data: 4-6 insights (focused on what's available)
- With moderate data: 6-8 insights (broader coverage)
- With rich data: 8-12+ insights (comprehensive analysis)

**No hardcoded limit!** The AI generates as many actionable insights as your data supports.
